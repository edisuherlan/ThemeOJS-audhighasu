## English

### Highlights

- Warm scholarly **orange** brand system
- Homepage research desk with latest articles & journal metrics
- Clean article pages with views + downloads charts
- Issue archive & search layouts tuned for academic journals
- Built-in **PDF flipbook** modal for galley reading
- Locales: English & Indonesian
- Compatible with the free [Journal Badges](https://github.com/edisuherlan/PluginOJS-JournalBadges) plugin (SINTA / partners strip)

### Minimum requirements

| Item | Minimum |
|------|---------|
| **OJS** | **3.5.0** or later |
| **PHP** | **8.1** or later |
| **Access** | Journal Manager / Site Administrator |

Tested on **OJS 3.5**. Not supported on OJS 3.3 / 3.4 without adaptation.

### Installation

1. Download this repository as ZIP (or `git clone`).
2. Rename the folder to **`audhighasu`** (required).
3. Copy it to:

   ```text
   <ojs-root>/plugins/themes/audhighasu/
   ```

4. Log in to OJS → **Settings → Website → Appearance**.
5. Under **Theme**, select **Audhighasu** → **Save**.
6. Optionally set primary/accent colours and homepage options on the same screen.
7. Clear browser cache / hard-refresh the public site.

#### Enable via Plugins (alternative)

**Settings → Website → Plugins → Theme Plugins** → enable **Audhighasu**, then select it under Appearance.

### After install (recommended)

- Upload logo & homepage image: **Settings → Website → Appearance → Setup**
- Add accreditation badges with [PluginOJS-JournalBadges](https://github.com/edisuherlan/PluginOJS-JournalBadges)
- Preview more themes live: **[https://ojs.audhighasu.com](https://ojs.audhighasu.com)**

### More themes & custom work

Audhighasu is a **free promotional theme**. For journals that need a stronger brand, premium layouts, or unique UX:

- Browse many ready-made OJS themes: **[https://ojs.audhighasu.com](https://ojs.audhighasu.com)**
- Order **custom theme builds** or **modifications** (colours, layout, homepage sections, PDF reader, etc.)
- Contact: **audhighasu@gmail.com** · [audhighasu.com](https://audhighasu.com)

### Uninstall

1. Switch Appearance to another theme.
2. Disable **Audhighasu** under Theme Plugins (optional).
3. Delete `plugins/themes/audhighasu/`.
